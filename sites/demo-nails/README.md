# Demo Nails

Negocio completamente ficticio que sirve como fixture del primer flujo punta a punta.

Archivos:

- `site.json`: identidad, contenido, contacto, ubicación y selección de módulos.
- `recipe.json`: composición permitida para el slice vertical del piloto.
- `assets.json`: procedencia, permiso y aprobación de assets.
- `assets/`: únicamente archivos propios, ficticios o autorizados registrados en el manifest.

No usar nombres, contactos, reseñas, fotografías ni identidad de un comercio real.
Validar el bundle con `pnpm validate:demo`.
