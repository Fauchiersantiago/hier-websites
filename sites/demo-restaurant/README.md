# demo-restaurant

Segundo negocio ficticio para probar la misma recipe con una dirección editorial y
fotografía generada de gastronomía. No representa un restaurante real, no recibe
reservas y su formulario no transmite ni persiste datos.

## Video stock de prueba

`assets/stock/` contiene una prueba de 10 segundos derivada de un clip de
[cottonbro studio en Pexels](https://www.pexels.com/video/a-plate-of-food-on-a-counter-in-a-restaurant-4253350/).
Se usa bajo la [licencia de Pexels](https://www.pexels.com/license/) y sólo para el
preview ficticio. La entrega incluye poster JPG, WebM y MP4 a 1280 × 720, sin audio;
el original permanece trazable mediante la URL de origen registrada en `assets.json`.
