# WS-04: Formularios

- **Estado:** Deferred para implementación real
- **Objetivo de la demo:** Mostrar interacción y estados de interfaz sin recolectar datos personales reales.

## Alcance inicial

- campos mínimos;
- validación accesible en cliente;
- estados de envío, éxito y error;
- consentimiento o aviso ficticio claramente marcado;
- endpoint simulado o seguro para la demo.

## Decisiones pendientes

- proveedor o backend;
- antispam;
- almacenamiento;
- email;
- retención y borrado;
- aviso de privacidad definitivo.

## Gate para producción

No activar recolección real hasta aprobar arquitectura, privacidad, retención, ownership y flujo de notificaciones.
