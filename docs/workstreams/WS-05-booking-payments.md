# WS-05: Booking y pagos

- **Estado:** Deferred
- **Objetivo actual:** Definir límites de integración, no construir sistemas propios.

## Decisiones vigentes

- En la primera etapa no se construye un calendario propio.
- Booking se integra como herramienta externa propiedad o responsabilidad del cliente.
- No se compran suscripciones antes de venta y aprobación.

## Pendientes

- proveedor o criterios de compatibilidad;
- enlace frente a embed;
- responsabilidad de configuración y soporte;
- procesador de pagos de Hier;
- cualquier flujo de anticipo del negocio;
- obligaciones fiscales y legales.

## Fuera de alcance de la demo

Transacciones reales, webhooks de producción, disputas, reembolsos, suscripciones y manejo de credenciales.
